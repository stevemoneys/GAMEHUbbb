Tetromino Skin Asset Layout
===========================

Provide 5 skin folders:
- assets/skins/skin-01/
- assets/skins/skin-02/
- assets/skins/skin-03/
- assets/skins/skin-04/
- assets/skins/skin-05/

Each skin folder must contain 7 tetromino images (one per piece type):
- I.webp (or .png/.jpg/.jpeg)
- O.webp (or .png/.jpg/.jpeg)
- T.webp (or .png/.jpg/.jpeg)
- S.webp (or .png/.jpg/.jpeg)
- Z.webp (or .png/.jpg/.jpeg)
- J.webp (or .png/.jpg/.jpeg)
- L.webp (or .png/.jpg/.jpeg)

Notes:
- The game auto-falls back through extensions: .webp -> .png -> .jpg -> .jpeg
- Images should be square (1:1) for best quality.
- The selected skin replaces tetromino tiles in gameplay and next-piece previews.
